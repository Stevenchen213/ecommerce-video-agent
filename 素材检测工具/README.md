# 素材检测工具

新素材进库前的质检脚本。**用法**：把视频放进素材目录，改脚本顶部的 `SRC`/`OUT` 路径，按顺序跑：

```bash
python analyze_pass1.py   # 元数据 + 抽帧联系表（人工快速分类用）
python analyze_pass2.py   # 卡顿/音量/静音 + 烧录字幕检测
```

## 输出

- `metadata.json`：时长/分辨率/fps/抽帧路径
- `quality.json`：卡顿次数、音量、静音段、`has_subtitles` 字幕标注
- `_字幕证据/`：字幕命中帧的底部条带截图（**误报复核用**——产品包装印刷字会触发，看证据图确认）

## 字幕检测原理

底部 30% 区域内「亮像素且邻域有暗像素」（亮字+深色描边）占比 > 0.012 判该帧有字幕，命中帧 >20% 判整条有字幕。阈值已用已知样本校准。

**纪律**：数字人训练素材必须 `has_subtitles=false`，否则生成的每条视频都会带幽灵字幕。
