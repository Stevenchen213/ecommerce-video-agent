# 交接说明

## 短片交到哪里

| 类型 | 放到 |
|------|------|
| 飞影 · 数字人短片 | `library/feiying/<shot_id>.mp4` |
| 蝉镜 · 产品 AI 短片（一小段一段） | `library/chanjing/<shot_id>.mp4` |

`shot_id` 必须和脚本 YAML 里一致。

## 编排侧做什么

1. 校验脚本顺序  
2. 检查缺镜  
3. 按脚本拼接成片（前端工作台 / API）  

生成 API 在各自平台侧完成后，把短片丢进对应 library 即可。

## 联调

1. 打开工作台 http://127.0.0.1:8790/  
2. 看缺镜列表  
3. 补齐短片后点「按脚本组装」
