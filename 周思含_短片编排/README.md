# 短片编排成片台

> 仓库目录名：`周思含_短片编排`（与旧目录区分）。旧架构保留不动。

## 一句话

**产品 AI 短片** + **数字人短片** → 本工作台按脚本编排拼接。  
含 **设置 / 可视化脚本 / 双工具生成进度 / 素材库 / 组装出片**。

## 启动

```powershell
cd "D:\电商视频剪辑AI\周思含_短片编排"
.\启动工作台.bat
```

浏览器会自动打开：http://127.0.0.1:8790/

## 工作台页签

| 页签 | 功能 |
|------|------|
| 脚本 | 可视化改分镜、上传/保存 YAML、导入分镜 JSON、成本估算 |
| 生成队列 | 飞影/蝉镜分队列进度条；支持只生成缺镜、Dry-run、Mock |
| 素材库 | 查看 `library/feiying|chanjing` 与缺镜 |
| 组装出片 | 校验、拼接、成片历史与预览 |
| 设置 | 双 API 配置、Mock 开关、连通性测试（密钥存本机 `data/settings.json`） |

## 落盘约定

| 来源 | 路径 |
|------|------|
| 飞影 · 数字人 | `library/feiying/<shot_id>.mp4` |
| 蝉镜 · 产品短片 | `library/chanjing/<shot_id>.mp4` |
| 成片 | `output/*.mp4` |

## 说明

- 默认 `use_mock=true`：无 Key 也能联调进度条与组装  
- **已综合蝉镜侧交付**：产品镜实拍 clips 本地裁切；图片 URL 走对方 `ai_creation` 图生短片  
- 设置里可填「蝉镜侧代码目录」（默认自动找 `_deps/.../路遥`）  
- 飞影填 Key 且关 Mock 后走 `create_by_tts`  
- 密钥与成片/短片**不进 Git**
