### P1 · 强烈建议有，否则对接易乱

#### 4. 一份「真业务」示例脚本

现在只有演示用 `examples/sample_script.yaml`。还缺：

- [ ] 真实带货结构的脚本（钩子 / 主播 / 特写 / 掰开 / CTA 等）
- [ ] 每镜写清：`platform`、`text`/`prompt`、目标时长
- [ ] 数字人镜补齐可用的 `person_id` / `voice_id`（或飞影侧等价 ID）
- [ ] 产品镜补齐提示词或素材要求

#### 5. 同伴交付规范（文件级）

即使 API 未通，也可先用「手扔 mp4」对接，仍缺成文规范确认：

- [ ] 文件必须命名为脚本里的 `shot_id`
- [ ] 目录：
  - 飞影 → `video_pipeline/library/feiying/`
  - 蝉镜 → `video_pipeline/library/chanjing/`
- [ ] 建议统一：竖屏 `1080x1920`、有音轨、H.264
- [ ] 交付后由谁执行 `assemble` / 谁点前端「仅组装」

#### 6. 品牌资产（可选但成片更完整）

放到 `video_pipeline/assets/brand/`：

- [ ] `logo.png`
- [ ] `bgm.mp3`（或 wav/m4a）
- [ ] `endcard.mp4`（片尾，可选）

无这些文件时组装仍可成功，只是没有包装层。
