## 双成片模式

```powershell
cd "D:\电商视频剪辑AI\脚本驱动双平台视频组装"

# 导出她能消费的 JSON（不调 API）
python -m video_pipeline.cli export-luyao video_pipeline\examples\sample_script.yaml

# 模式 B：主架构拼镜（默认 mock）
python -m video_pipeline.cli run video_pipeline\examples\sample_script.yaml --mode b

# 模式 A：路遥切轨（需 person/voice；可先 dry-run）
python -m video_pipeline.cli run video_pipeline\examples\sample_script.yaml --mode a --dry-run --person-id C-PLATFORM-DEMO-001 --voice-id <voice>
```
